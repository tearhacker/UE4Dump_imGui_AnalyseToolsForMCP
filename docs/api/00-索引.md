## 每份文档的统一格式

```markdown
# L? 层名 · 模块名
> 源码路径与规模
> 已精读范围（未覆盖的在文末列出）

## 0. 全局约定        ← 读代码前必知的宏、缓存机制、空值语义
## 1..N. 各接口       ← 签名 | 行为 | 边界条件 | 行号
## N+1. MCP 封装陷阱清单
## N+2. 本次未精读范围
```

每个接口必须回答四个问题：
1. **签名是什么**（照抄源码，不改写）
2. **失败时返回什么**（`"None"` 还是 `""`？`nullptr` 还是 `{}`？`0` 还是 `-1`？）
3. **边界条件是什么**（越界、偏移为 0、未初始化）
4. **有什么陷阱**（性能、误用、版本差异）

## 已发现的跨模块约定

### 空值语义不统一（必须逐接口确认）

| 场景 | 返回 | 出处 |
|---|---|---|
| FName 解析失败 | `"None"`（**非空串**） | `UEWrappers.cpp:150,158,161` |
| UObject 属性失败 | `""` | `UEWrappers.cpp:223,231,245` |
| `UE_UObject::GetIndex()` | `-1` | `:190` |
| `UE_UObject::GetFlags()` | `NoFlags` | `:183` |
| 偏移表项为 0 | `0` / 空对象 | `:531-532,742-743,753-754` |

### 偏移为 0 = 该版本不支持

`getter` 普遍写成 `offset ? vm_rpm_ptr<T>(object + offset) : 0`。
**偏移表里为 0 的项表示"当前 UE 版本无此字段"，不是"偏移是 0"。**

### `UE_STATIC_CLASS_CACHED` 按代数缓存

所有 `StaticClass()` 惰性查找并按 `gInitGen` 缓存。
`UEWrappers::Init()` 递增代数 → **切进程必须重新 Init**。

### 全局单例，非线程安全

`UEWrappers::GUVars` / `pObjectsArray` 是文件级全局。
**命令服务必须串行调用本层接口。**

## 质量红线

写每份文档时，**以下情况必须显式标注而不是猜测**：

- 未读到的实现 → 「本次未精读范围」列出行号区间
- 语义不确定的参数 → 标注 `（语义待确认）`
- 疑似源码 bug → 标注 `⚠️ 疑似 bug` 并说明依据
- 版本相关行为 → 标注适用版本

**宁可留白，不可编造。** 编造的接口做出来的 MCP 工具必然是错的。
