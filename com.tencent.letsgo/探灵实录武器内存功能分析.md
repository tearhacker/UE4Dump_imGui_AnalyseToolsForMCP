# 探灵实录模式 - 武器/攻击物品内存功能分析

## 一、电锯物品定位

电锯在 `weapons.h` 中的映射为 **ID = 14010010**，归类为"工具类"近战武器。

```
{14010010, "电锯"},
{14010011, "电镐"},
```

电锯在探灵实录 PVE 模式中作为近战武器使用，走 `AWeapon` + `WeaponFireComponent_Melee` 路径。武器获取链路：
```
selfEntity+0xAB8(CacheCharInventoryComponent) -> +0xC8(CrtEquipWeapon) -> AWeapon实例
```

## 三、服务端校验深度分析

### 3.1 服务端权威字段（不可修改，会被回滚）

| 类 | 字段 | 偏移 | 标记 | 结论 |
|---|---|---|---|---|
| UChestPVECombatSet | ATK / ATKBase / ATKFlat | 0x00B0/0x00C0/0x00D0 | Net,RepNotify | **服务端权威，改了会被覆盖** |
| UChestPVECombatSet | DamageIncreasePercent | 0x0110 | Net,RepNotify | **服务端权威** |
| UChestPVECombatSet | DamageReductionPercent | 0x0120 | Net,RepNotify | **服务端权威** |
| UChestPVECombatSet | MoveSpeed / MoveSpeedBase | 0x0080/0x0090 | Net,RepNotify | **服务端权威** |
| UChestPVELifeComponent | DeathState | 0x00D0 | Net,RepNotify | **服务端权威** |
| UChestPVEEquipmentManagerComponent | EquippedEquipmentID | 0x0200 | Net,RepNotify | **服务端权威** |
| UChestPVEWeaponEquipmentInstance | SourceItemID | 0x0190 | Net,RepNotify | **服务端权威** |

### 3.2 服务端RPC校验（操作需过服务端）

所有背包/物品操作走 `Server_*` RPC，服务端校验后执行：
- `Server_AddItem` / `Server_RemoveItem` / `Server_SetDurability`
- `Server_SetBaseItemDynicValue` / `Server_SetBaseItemDynicValuef`
- `Server_ChangeItemIndex` / `Server_SetBagNum` / `Server_SetEmptyBag`

生命值变化通过 **Watcher 模式**（`OnHealthChangedFromWatcher`）从服务端推送，客户端无法直接修改血量。

### 3.3 可安全修改的字段（无服务端校验）

**AWeapon 实例上的所有战斗属性（Damage/Range/Collider等）均无 Net 标记**，属于客户端本地计算字段。

伤害计算流程分析：
```
客户端AWeapon.Damage(0x600) → 客户端计算伤害 → 应用到目标
                                        ↓
                           服务端Watcher监控血量变化（仅记录/同步，不重新计算）
```

**关键证据：**
1. ChestPVE 模块中未找到任何 `Server_*Damage` 或 `Server_*Attack` RPC
2. `CheckDamageValid` / `CheckAmmoValid` 是客户端本地校验函数
3. `SvrCheck*` 字段仅校验射击频率和弹道索引，不校验伤害数值
4. 现有代码已成功修改 Damage/Range/FireInterval 等字段且未触发封禁

### 3.4 服务端校验总结

| 维度 | 校验强度 | 可修改性 | 说明 |
|---|---|---|---|
| 战斗属性(ATK/移速/伤害加成) | **强** (Net+RepNotify) | 不可改 | 服务端权威，改了秒回滚 |
| 生命值/死亡状态 | **强** (Net+RepNotify+Watcher) | 不可改 | 服务端监控推送 |
| 背包/物品/耐久 | **强** (Server RPC) | 不可改 | 所有操作过服务端RPC |
| 装备ID | **强** (Net+RepNotify) | 不可改 | 服务端权威 |
| **武器实例属性(伤害/射程/范围)** | **弱** (无Net标记) | **可改** | 客户端本地字段 |
| **攻击碰撞箱(范围伤害)** | **弱** (无Net标记) | **可改** | 客户端本地字段 |
| 射击频率/弹道 | **中** (SvrCheck字段) | 谨慎改 | 有射击频率校验，用倍率不用极端值 |

## 四、范围伤害实现方案

### 方案A：扩大攻击碰撞箱（推荐，电锯/近战核心）

修改 `AttackColliderExtent`(0x0554, FVector) 使近战武器覆盖更大范围：

```
原始: AttackColliderExtent = (50, 50, 50)   // 小范围
修改: AttackColliderExtent = (500, 500, 500) // 大范围AOE
```

适用武器：电锯(14010010)、大砍刀(16020004)、狼牙棒(16020003)等所有近战武器。

实现要点：
- 获取武器指针: `selfEntity+0xAB8 -> +0xC8`
- 读原始值并保存
- 写入扩大后的碰撞箱尺寸
- 恢复时写回原始值

### 方案B：伤害距离衰减消除

修改 `DamageDistanceMap`(0x0610) 或将 `DamageRateDataTable`(0x0660) 置空，使远距离不衰减伤害。

### 方案C：持续伤害区域

将 `bContinuousFire`(0x049E) 改为 true + `bAlwaysCheckDamage`(0x584) 改为 true，使近战武器在攻击动作期间持续造成伤害（电锯特别适用）。

### 方案D：锁定范围扩大

修改 `MaxLockTargetRange`(0x0604) 和 `MaxLockTargetAngle`(0x0608)，扩大自动锁定范围。

## 五、飞剑系统（探灵实录特有武器）

探灵实录有独特的飞剑武器系统，配置在 `UChestPVEFlyingSwordDataAsset`（DataAsset，非网络复制）：

| 配置结构体 | 关键字段 | 偏移 | 可修改性 |
|---|---|---|---|
| FFlyingSwordChaseConfig | AttackDamage | +0x000C | 可改(本地DataAsset) |
| FFlyingSwordChaseConfig | AttackReachDistance | +0x001C | 可改(本地DataAsset) |
| FFlyingSwordChaseConfig | DetectRadius | +0x0000 | 可改(本地DataAsset) |
| FFlyingSwordChaseConfig | ChaseSpeed | +0x0004 | 可改(本地DataAsset) |
| FFlyingSwordChaseConfig | AttackInterval | +0x0010 | 可改(本地DataAsset) |
| FFlyingSwordChaseConfig | MaxChaseDistance | +0x0014 | 可改(本地DataAsset) |

飞剑配置是 `UDataAsset` 子类，从本地配置加载，**完全不走网络同步**，是安全的修改目标。

## 六、风险评估与建议

### 低风险（推荐实现）
1. **AttackColliderExtent 范围扩大** - 无Net标记，纯客户端碰撞检测
2. **MaxLockTargetRange/Angle 锁定扩大** - 无Net标记，客户端锁定逻辑
3. **bContinuousFire 持续伤害** - 无Net标记，电锯天然持续伤害
4. **飞剑配置修改** - DataAsset非网络复制

### 中风险（需用倍率）
5. **Damage 伤害增强** - 无Net标记但有SvrCheck射击校验，用倍率(5x)不用极端值
6. **FireInterval 射速** - SvrCheck校验射击频率，用倍率(2x)不用0
7. **CheckDamageInterval 多重倍击** - 同上，用倍率不用0

### 高风险（不建议）
8. ATK/DamageIncreasePercent 直接改 - Net+RepNotify，秒回滚
9. 背包物品直接添加/修改 - Server RPC校验
10. 血量直接修改 - Watcher监控

### 实现优先级建议

| 优先级 | 功能 | 字段 | 难度 | 风险 |
|---|---|---|---|---|
| P0 | 近战范围扩大(AOE) | AttackColliderExtent@0x554 | 低 | 低 |
| P0 | 电锯持续伤害 | bContinuousFire@0x49E + bAlwaysCheckDamage@0x584 | 低 | 低 |
| P1 | 锁定范围扩大 | MaxLockTargetRange@0x604 | 低 | 低 |
| P1 | 持武器不减速 | speedDecPercent@0x50C | 低 | 低 |
| P2 | 飞剑伤害/范围增强 | FlyingSwordDataAsset | 中 | 低 |
| P2 | 伤害距离衰减消除 | DamageDistanceMap@0x610 | 中 | 低 |
